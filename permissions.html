لا يطلب التطبيق إذن الوصول الشامل إلى ذاكرة الهاتف (READ_EXTERNAL_STORAGE أو MANAGE_EXTERNAL_STORAGE). عند قيامك بمشاركة صورة أو ملف PDF أو نص مع التطبيق، يقرأ التطبيق الملف مؤقتاً عبر آلية النظام الآمنة (FileProvider) لتحويله إلى أوامر طباعة، ثم يتم مسحه من الذاكرة المؤقتة فوراً.

  • الكاميرا والميكروفون وجهات الاتصال: غير مطلوبة تماماً.

Permissions Disclosure (English)

Last Updated: November 27, 2026 | Developer: Karam.apk | App: Pr3 stydeo pro

Prominent Disclosure: Pr3 stydeo pro uses Bluetooth / Nearby Devices permissions solely to connect to paired thermal receipt printers and transmit print jobs. Bluetooth scanning is explicitly configured with neverForLocation, and the app never collects, stores, or transmits location data or personal documents to external servers.

1. Declared Android Permissions

Android Permission API Scope Purpose & Functionality
BLUETOOTH_CONNECT Android 12+ (API 31+) Connects to user-paired Bluetooth thermal printers to send formatted Arabic receipts, images, and PDF print commands.
BLUETOOTH_SCAN
(neverForLocation)		 Android 12+ (API 31+) Discovers nearby Bluetooth printers for printing purposes only. Explicitly flagged with neverForLocation so it cannot be used to derive physical location.
BLUETOOTH & BLUETOOTH_ADMIN Android 11 & below
(maxSdkVersion="30")		 Backward compatibility for establishing Bluetooth serial connections with thermal printers on legacy Android versions.
BIND_PRINT_SERVICE System Print Framework Registers PR3PrintService as a native Android Print Service so users can print directly from any app's Print menu.
INTERNET Network Used exclusively for verified App Links (karamegy.github.io) and viewing documentation or policy pages upon user action.

2. Scoped File Handling (No Broad Storage Access)

The app does not request broad storage permissions (READ_EXTERNAL_STORAGE or MANAGE_EXTERNAL_STORAGE). Files (images, PDFs, plain text) shared via Android's ACTION_SEND or Print framework are processed temporarily in local memory using FileProvider and discarded immediately after printing.

3. Permissions Never Requested

  • Location (Fine / Coarse / Background GPS): Never requested.
  • Contacts, Camera, Microphone, or Call Logs: Never requested.
